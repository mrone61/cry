Cara Kerja Sistem

CryptoSecure Vault menjamin dua aspek utama keamanan: kerahasiaan dan keutuhan data. Dilindungi AES-256-GCM & SHA-512, sesuai Standar Post-Quantum NIST.

1. Kunci Super - Password + Kunci Server

Password yang kamu ketik tidak langsung dipakai. Password digabung dengan Kunci Rahasia Server, lalu diolah menggunakan PBKDF2-HMAC-SHA512 sebanyak 600.000x untuk menghasilkan kunci enkripsi. Jadi meskipun ada yang tahu password kamu, tanpa Kunci Server dia tetap tidak bisa membuka. Penggunaan SHA-512 membuat kunci tahan terhadap serangan brute-force dan serangan komputer kuantum (Algoritma Grover).

2. Enkripsi Teks - AES-256-GCM (Anti-Kuantum)

Pesan teks dienkripsi menggunakan AES-256-GCM, sesuai Standar Post-Quantum NIST. Versi ini menggunakan kunci 256-bit sehingga meskipun diserang komputer kuantum dengan Algoritma Grover, kekuatannya masih setara AES-128 dan tetap mustahil dibobol. Setiap pesan memakai Salt 32 byte + Nonce acak yang baru, jadi pesan yang sama akan menghasilkan token yang selalu berbeda. Format token baru diawali PQv2.

3. Enkripsi File - AES-256-CTR + HMAC-SHA512 Streaming

Untuk file (Gambar, Audio, Video, PDF, CSV), sistem memakai AES-256-CTR + HMAC-SHA512 mode Streaming. File dibaca per 64 KB, dienkripsi per potong, tidak pernah diload 20 MB sekaligus ke RAM. Saat didekripsi, file tidak lagi ditampilkan di web, tapi langsung di-download dengan nama asli agar browser tidak berat. Maksimal ukuran file 20MB.

4. Dekripsi - Verifikasi Sebelum Dibuka

Sistem memverifikasi HMAC-SHA512 terlebih dahulu. Jika valid dan kunci sesuai, pesan atau file dikembalikan ke bentuk asli. Jika ada satu karakter saja yang diubah pada token, sistem akan menolak dan menganggap token rusak / password salah.

5. Token Hangus 1x Pakai - Burn After Reading

Setiap token hanya bisa dibuka 1x saja. Begitu berhasil dibuka, sidik jari token (SHA-256) langsung dimasukkan ke daftar hitam dan dimusnahkan. Jika token yang sama dicoba dibuka lagi, sistem akan menolak dengan pesan "Token ini SUDAH HANGUS".

6. Anti Brute Force - Hukuman Bertingkat

Sistem menghitung percobaan gagal per IP + per Token. Jika salah password 3x, token langsung terkunci. Hukumannya bertingkat dan makin lama:

- Gagal 3x = Terkunci 1 Menit
- Gagal 6x = Terkunci 1 Jam
- Gagal 9x = Terkunci 1 Hari
- Gagal 12x = Terkunci 7 Hari
- Gagal 15x = Terkunci 30 Hari

7. Keamanan Server & Ketahanan Kuantum

AES-256 merupakan standar enkripsi yang digunakan di perbankan dan instansi pemerintah, dan dinyatakan Quantum-Resistant oleh NIST. Komputer kuantum dengan Algoritma Grover hanya mampu memotong kekuatan kunci menjadi setengah, sehingga AES-256 tetap aman. Sedangkan Algoritma Shor yang mampu membobol RSA / ECC tidak berpengaruh ke sistem ini karena Vault tidak menggunakan RSA sama sekali. Input file dibatasi maksimal 20 MB untuk mencegah penyalahgunaan server.

8. Token Lama Tidak Berlaku

Sejak upgrade ke standar Anti-Kuantum, token lama (Fernet / AES-128 dan HMAC-SHA256) tidak dapat lagi dibuka. Silakan buat token baru dengan format PQv2. untuk teks dan FILEv2. dengan HMAC-SHA512 untuk file.
