Cara Kerja Sistem

CryptoSecure menjamin dua aspek utama keamanan: kerahasiaan dan keutuhan data.

1. Kunci Super - Password + Kunci Server

Password yang kamu ketik tidak langsung dipakai. Password digabung dengan Kunci Rahasia Server, lalu diolah menggunakan PBKDF2-HMAC-SHA256 sebanyak 600.000x untuk menghasilkan kunci enkripsi. Jadi meskipun ada yang tahu password kamu, tanpa Kunci Server dia tetap tidak bisa membuka.

2. Enkripsi Teks - Fernet (AES-128 CBC + HMAC)

Pesan teks dienkripsi menggunakan Fernet menjadi kode acak, kemudian ditandatangani dengan HMAC-SHA256 agar tidak dapat diubah. Setiap pesan memakai Salt acak yang baru, jadi pesan yang sama akan menghasilkan token yang selalu berbeda.

3. Enkripsi File - AES-CTR + HMAC Streaming

Untuk file (Gambar, Audio, Video, PDF, CSV), sistem memakai AES-CTR + HMAC-SHA256 mode Streaming. File dibaca per 64 KB, dienkripsi per potong, tidak pernah diload 20 MB sekaligus ke RAM. Saat didekripsi, file tidak lagi ditampilkan di web, tapi langsung di-download dengan nama asli agar browser tidak berat. Maksimal ukuran file 20MB.

4. Dekripsi - Verifikasi Sebelum Dibuka

Sistem memverifikasi HMAC terlebih dahulu. Jika valid dan kunci sesuai, pesan atau file dikembalikan ke bentuk asli. Jika ada satu karakter saja yang diubah pada token, sistem akan menolak dan menganggap token rusak / password salah.

5. Token Hangus 1x Pakai - Burn After Reading

Setiap token hanya bisa dibuka 1x saja. Begitu berhasil dibuka, sidik jari token (SHA-256) langsung dimasukkan ke daftar hitam dan dimusnahkan. Jika token yang sama dicoba dibuka lagi, sistem akan menolak dengan pesan "Token ini SUDAH HANGUS".

6. Anti Brute Force - Hukuman Bertingkat

Sistem menghitung percobaan gagal per IP + per Token. Jika salah password 3x, token langsung terkunci. Hukumannya bertingkat dan makin lama:

- Gagal 3x = Terkunci 1 Menit
- Gagal 6x = Terkunci 1 Jam
- Gagal 9x = Terkunci 1 Hari
- Gagal 12x = Terkunci 7 Hari
- Gagal 15x = Terkunci 30 Hari

7. Keamanan Server

AES-128 merupakan standar enkripsi yang digunakan di perbankan. Input file dibatasi maksimal 20 MB untuk mencegah penyalahgunaan server.
